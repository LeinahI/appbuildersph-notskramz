# Dev server port 3000 already in use

- Date: 2026-10-10
- Agent: Codex (GPT-6)
- Status: done

## Task
Explain why pnpm run dev stops with Port 3000 is already in use.

## What changed
- No code changes. Windows reported node.exe PID 11972 listening on ::1:3000, running this repository's web/node_modules Vite executable.
- Added this note and its link in [Home.md](../../Home.md).

## Decisions
[web/vite.config.ts](../../web/vite.config.ts) sets port 3000 and strictPort for dev and preview. A second server must stop because an existing Ugatan dev server owns that port. Reuse the server at http://localhost:3000, or stop its original terminal with Ctrl+C before restarting. No process was stopped or port configuration changed.
Related: [[2026-10-10-reconcile-frontend-main-merge]], [[2026-10-09-web-port-3000]].

## Verification
- Get-NetTCPConnection and Get-CimInstance identified the listener and Vite command.
- HTTP GET http://localhost:3000/ returned 200 with /@vite/client and /src/main.tsx references.
- Build, tests and browser interaction checks were not run for this diagnosis.

## Follow-ups
If a restart is needed and the original terminal is unavailable, recheck the owning process before stopping it; PID values can change.
